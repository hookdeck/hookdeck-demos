{ LiveKit call log }

A call log built from room webhooks

LiveKit sends room, participant and egress (recording) events to a Hookdeck source. Hookdeck delivers them to this server, which builds one entry per room session: start, end, duration, participants and recording links. Watch each webhook arrive in the Data flow pane at the bottom of the page.

Failure injection

Make this app misbehave, then watch Hookdeck absorb it: the event stays queued and is retried until the app answers 2xx. LiveKit itself is never kept waiting.
