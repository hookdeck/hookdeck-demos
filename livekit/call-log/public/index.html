A spoken adventure, told by room webhooks

Join a call, and an AI innkeeper and storyteller run a short adventure for you and any friends. At each new scene this server pulls a soundtrack into the room with LiveKit's Ingress API. LiveKit reports everything that happens (people joining, dropping, soundtracks starting and ending) as webhooks to a Hookdeck source, and Hookdeck delivers them to this server, which builds a call log and a session chronicle from them. Watch each webhook arrive in the Data flow pane at the bottom of the page.

Join a call

Joins a LiveKit room from this browser with your microphone. Hester, the innkeeper, asks for your name, then fetches Old Bram, who tells the story. Open this page in a second tab to play with two voices, or add a silent bot player. Only one player is heard at a time: the storyteller gives each a turn. Allow the microphone when the browser asks, and start the agent with npm run agent.
