{ Hookdeck Event Gateway }

Transformations with Node.js built-ins

Each example is a connection with its own transformation. Send a JSON event and follow it from the source, through a transformation that imports node:zlib, node:crypto or node:buffer, to hookdeck listen delivering the result to this server: a PNG, a WAV, a PDF, an SVG, a signed request, or JSON decompressed from a binary payload. No npm packages and no bundling.
