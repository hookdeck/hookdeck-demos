{ Vapi + Hookdeck Event Gateway }

Vapi agency routing with Hookdeck

One Vapi assistant and one endpoint per client.

How this demo works

A voice AI agency runs one Vapi assistant for each of its clients. Each assistant sends its call webhooks to that client's own Event Gateway source, which verifies Vapi's signature and delivers them to that client's endpoint in this app.

You are the caller. Click the call button on a client's card and talk to its assistant. The card then lists every webhook that client's endpoint received during the call. The Data flow pane at the bottom of the page shows each webhook moving from Vapi through Event Gateway to the endpoint, and the lookup result going back into the call.
