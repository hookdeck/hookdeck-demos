How it works

ElevenLabs sends a webhook when a conversation ends. Hookdeck verifies the ElevenLabs-Signature, drops duplicates, retries failures and delivers each event to this app. Watch it happen in the Data flow pane below.

About this call

Start a voice call from this page (the browser asks for your microphone), say something, then End call. A few seconds later the post-call webhooks arrive below.

About the booking assistant

An ElevenLabs agent that answers as the phone booking assistant for Hookdeck Hair, a hair salon. It greets you, then asks for the service, the day and time, and your name. Any slot between 9am and 6pm, Monday to Saturday, is free. It has no tools, so it never looks anything up.

About the retry demo

Make the next deliveries fail with a 500. Hookdeck retries them on its schedule; once this counter reaches zero the app recovers and a retry succeeds. You can also replay any event from the Hookdeck dashboard.

About the diary

Each finished call with booking_made: success adds a slot here, read from caller_name, requested_service and requested_time. A call where the caller did not agree a time adds nothing. A time this page cannot read as a day and a time goes in the Unscheduled row.
